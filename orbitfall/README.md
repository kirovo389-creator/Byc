# Осколки неба

Полностью офлайн-аркада для Android: веди корабль пальцем, уворачивайся от астероидов и собирай золотые осколки. Каждые четыре осколка восстанавливают заряд щита. По мере полёта скорость и частота препятствий растут, а рекорд сохраняется локально на устройстве.

## Управление
- Коснись экрана, чтобы начать.
- Веди корабль пальцем влево и вправо.
- Нажимай круглую кнопку «Щит» внизу справа, чтобы потратить заряд и пережить столкновение.
- Кнопка «Пауза» находится сверху справа.

## Сборка
Открой каталог `orbitfall` в Android Studio и собери вариант Release. Проект использует Android SDK 35, минимальная версия Android — 6.0 (API 23). Приложение не запрашивает разрешений, не использует сеть и хранит только рекорд в SharedPreferences.

GitHub Actions автоматически собирает подписанный APK и публикует его в Releases после изменения проекта.
